# Research2Report - 보고서만 / 전체 산출물 다운로드 범위 선택

산출물 다운로드 메뉴에 다운로드 범위 선택을 추가했습니다.

- 보고서만: 생성·개선 보고서 본문만 PDF / Word / PNG로 저장
- 전체 산출물: Research Overview, Evidence, 보고서 검증 결과, 보고서, 문헌 후보 등을 포함
- 보고서가 아직 생성되지 않은 경우 `보고서만`은 비활성화되고 전체 산출물만 저장할 수 있습니다.
- 기존 보고서 검증까지만 수행한 경우, 보고서만 내보내기는 검증 주석을 제외한 기존 보고서 본문을 저장합니다.

PDF는 브라우저 인쇄 기능, Word는 docx, PNG는 html2canvas를 사용합니다.
